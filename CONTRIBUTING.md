# Contributing to env-doctor

Thanks for your interest! Here's how to get started.

## Setup
```bash
git clone https://github.com/ajju853/env-doctor
cd env-doctor
npm install
npm test
```

## Making changes
- All source is in `src/`
- Tests are in `test/` — please add tests for new features
- Run `npm run build` to verify the build passes before submitting

## Pull requests
- Keep PRs focused — one feature or fix per PR
- Update README if you add a new type or option
- All tests must pass

## Reporting bugs
Open an issue with the error output and your schema definition.
